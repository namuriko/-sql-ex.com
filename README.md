# SQL-EX — Решение задач

Мой учебный проект по изучению SQL. Здесь я собираю решения задач с сайта [SQL-EX](https://www.sql-ex.com/), практикую написание SQL-запросов и закрепляю знания.

## О проекте

- **Источник задач:** SQL-EX
- **Язык запросов:** SQL
- **Количество решённых задач:** 99

## Решения
В этом репозитории собраны мои решения задач. Каждая задача будет оформлена в отдельном SQL-файле с номером и условием задачи в комментариях.

## Цель проекта

Систематически практиковаться в SQL, учиться самостоятельно решать задачи и формировать портфолио для дальнейшего профессионального развития.
